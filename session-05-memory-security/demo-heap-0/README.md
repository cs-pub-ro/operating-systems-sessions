Warm-up challenge, solved together with the teaching assistant at the
start of the session.

My data isn't on the stack, so it should be safe... right?

## Files

- `chall.c` -- the challenge source code.
- `chall` -- the compiled challenge binary. Run it locally with `./chall`
  (it looks for `flag.txt` in the current directory).

## Hints

What part of the heap do you have control over, and how far is it from
`lock_state`?
