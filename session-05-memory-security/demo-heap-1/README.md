Warm-up challenge, solved together with the teaching assistant at the start of the session.

Same idea as `demo-heap-0`, but this time you don't just need to *change* a value on the heap -- you need it to become one *specific* value.

## Files

* `chall.c` -- the challenge source code.
* `chall` -- the compiled challenge binary.
  Run it locally with `./chall` (it looks for `flag.txt` in the current directory).

## Hints

1. How can you tell where `access_level` starts?
1. What string does `check_win()` actually compare `access_level` against?
